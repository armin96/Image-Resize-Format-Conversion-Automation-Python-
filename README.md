# Image Resize Format Conversion Automation Python

Image Resize & Format Conversion Automation (Python)

A bulk image processing automation tool.
Resizes images and converts formats while preserving aspect ratio.
![okk](https://github.com/user-attachments/assets/a3da4898-be13-4c61-83e2-40639d08fd7b)


FEATURES
--------
- Bulk image resizing
- Format conversion (JPG, PNG, WEBP)
- Aspect ratio preserved
- Folder-based automation
- Preview mode (safe)
- No GUI, fast CLI automation

USAGE
-----
1. Install dependency:
   pip install pillow

2. Run:
   python image_tool.py

3. Choose:
   - Input folder
   - Output folder
   - Max width & height
   - Output format
   - Preview mode

SUPPORTED FORMATS
-----------------
.jpg
.jpeg
.png
.webp

AUTOMATION VALUE
----------------
This tool automates repetitive image resizing and format conversion tasks,
saving time and ensuring consistent output across large image sets.
